# Space VR Game

This repository contains a simple VR demo built with [A-Frame](https://aframe.io/).

## Nasıl Çalıştırılır

1. `index.html` dosyasını modern bir tarayıcıda açın.
2. WASD tuşlarıyla veya VR kumandalarınızla uzay ortamında dolaşın.

Bu basit demo, yıldızlar, küçük bir uzay gemisi ve bir gezegen içerir.
