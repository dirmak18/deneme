# Space VR Game

Bu depo, [A-Frame](https://aframe.io/) ile gelistirilmis basit bir VR uzay oyununu icermektedir.

## Nasıl Çalıştırılır

1. `index.html` dosyasını modern bir tarayıcıda açın.
2. WASD tuşlarıyla veya VR kumandalarınızla ortamda dolaşın.
3. Kırmızı küplere yaklaşarak onları toplayın ve skorunuzu artırın.

Bu demoda yıldızlar, bir uzay gemisi, gezegen ve toplanabilir küpler bulunur. Skorunuz ekranın ortasında görüntülenir.
